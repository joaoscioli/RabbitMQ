# Live Review Script

Use this script when sharing the repository during an interview.

## Opening

This repository explains RabbitMQ through topology, delivery guarantees, and failure handling.

## Walkthrough order

1. Start with `README.md` and the local setup.
2. Explain exchanges, queues, routing keys, and naming.
3. Show retry, dead-letter, and idempotency notes.
4. Discuss observability and replay strategy.
5. Close with a business flow that needs asynchronous messaging.

## Strong signal

The repository shows operational understanding of messaging, not only producer-consumer basics.
