# Interview Route

Use this route to navigate the repository during a technical interview.

## Start Here

Open the README and explain that this is a RabbitMQ messaging lab for backend
architecture and reliability.

## Show The Core Concepts

Start with exchanges, routing, DLQs, idempotency, retry, replay, and producer
safeguards. Connect each concept to a failure mode.

## Discuss Engineering Judgment

Use the observability, backpressure, and consumer error handling docs to explain
why messaging systems need operational thinking.

## Close With The Next Step

Explain that a consumer with explicit acknowledgement and duplicate handling
would turn the reliability documentation into a stronger runnable example.
