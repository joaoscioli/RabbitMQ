# 30-Second Pitch

This repository is a RabbitMQ messaging lab for backend systems.

It demonstrates asynchronous architecture thinking through exchanges, queues,
routing keys, retries, dead-letter queues, idempotency, replay, backpressure,
consumer errors, and producer safeguards.

In an interview, I would use this repository to discuss message reliability,
failure modes, duplicate handling, and when asynchronous design is worth the
operational complexity.
