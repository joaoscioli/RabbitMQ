# Recruiter Summary

This repository is a messaging portfolio project focused on RabbitMQ and
asynchronous architecture.

## What It Shows

- Producer-consumer flow, routing, retry, and DLQ thinking.
- Idempotency, replay, backpressure, and message-contract documentation.
- Failure-aware architecture instead of only happy-path messaging.
- Strong interview material for distributed-system trade-offs.

## Best Fit Signal

Use this project as evidence for backend integration, event-driven design, and
operational thinking around asynchronous systems.
