# Senior Demo Path

Use this repository to explain asynchronous architecture with operational awareness.

## 1. Start with why messaging exists

Explain decoupling, load smoothing, retry isolation, and eventual consistency. Avoid presenting RabbitMQ as only a queue tutorial.

## 2. Show topology decisions

Walk through exchanges, queues, routing keys, dead-letter queues, and naming conventions.

## 3. Discuss failure modes

Senior reviewers will ask about retries, poison messages, idempotency, backpressure, and observability.

## 4. Connect to business flow

Use examples such as billing events, notification delivery, order processing, or audit trails to make the architecture concrete.
