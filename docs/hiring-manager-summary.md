# Hiring Manager Summary

This repository supports the portfolio by showing messaging architecture.

## Why It Matters

It demonstrates asynchronous backend thinking through RabbitMQ concepts and
reliability patterns.

## What To Notice

- Documentation for exchanges, routing, queues, retries, and DLQs.
- Idempotency, replay, backpressure, and consumer error handling.
- Producer-side safeguards for unroutable messages.
- Local RabbitMQ setup for reproducible learning.

## Interview Signal

This project is useful for discussing event-driven workflows, failure modes,
message reliability, and when async architecture is worth the complexity.
