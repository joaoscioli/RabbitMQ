# Reviewer Question Bank

Use these questions to prepare for a technical walkthrough.

## Questions To Expect

- How does the consumer handle duplicate messages?
- What happens after retries are exhausted?
- When should a message go to a dead-letter queue?
- How would you replay failed messages safely?
- How do producer and consumer teams avoid contract drift?

## Strong Answer Direction

Anchor answers in idempotency, bounded retries, DLQs, replay controls, and
versioned message contracts.
