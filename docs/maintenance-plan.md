# Maintenance Plan

This plan keeps the project credible as a messaging portfolio.

## Monthly Review

- Re-run local broker setup instructions.
- Review retry, DLQ, replay, and idempotency notes for consistency.
- Add one failure scenario that can be explained in an interview.

## Next Maintenance Targets

- Add a Docker Compose producer and consumer lab.
- Include metrics examples for queue depth, retries, and dead letters.
- Demonstrate idempotency with persistence-backed message handling.

## Interview Signal

Maintained messaging docs show operational thinking around asynchronous systems,
not only the ability to publish and consume messages.
