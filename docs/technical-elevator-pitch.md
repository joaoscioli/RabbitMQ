# Technical Elevator Pitch

This project is an asynchronous architecture portfolio focused on RabbitMQ,
producer-consumer flows, retries, dead-letter queues, replay, idempotency, and
message contracts.

## 30-Second Version

"I built this repository to show how I reason about messaging beyond the happy
path. The main signal is failure handling: duplicate delivery, bounded retries,
DLQs, replay controls, and contract evolution between producers and consumers."
