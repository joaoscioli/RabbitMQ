# Portfolio Positioning

This is a supporting messaging architecture repository in the portfolio.

## What It Proves

- Understanding of asynchronous backend communication.
- RabbitMQ concepts such as exchanges, routing keys, queues, retries, and DLQs.
- Reliability thinking around idempotency, replay, backpressure, and failures.
- Ability to discuss when messaging helps and when it adds complexity.

## How To Present It

Present this repository when the conversation moves to distributed workflows,
background processing, event-driven design, or integration reliability.

## Best Interview Angle

Start with idempotency and dead-letter handling because they show real
production concerns, not only local messaging examples.
