# Pre-Interview Checklist

Use this checklist before presenting the repository.

## Review Before The Call

- Open the fast review path and interview case study.
- Prepare a duplicate-message scenario.
- Know how retries, DLQs, replay, and idempotency fit together.
- Be ready to explain when async messaging adds unnecessary complexity.

## Be Ready To Show

- dead-letter queue docs
- idempotency docs
- retry strategy docs
- producer safeguard configuration

## Strong Close

Explain that RabbitMQ reliability comes from explicit failure handling, not from queues alone.
